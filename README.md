# FlexBox Project
### *What does it do?*

This project basically is just a test of FlexBoxes for a class assignment. The FlexBox code is showing different **potential** ways to distribute FlexBox layouts. It is **not** a comprehensive guide.

### *How can I run the FlexBox Project?*

Very easily! Fortunately there are two ways to do it.

* You can run it from GitHub pages in the browser.
* You may also run it by downloading it and opening it in a browser of your choice.

### *What makes FlexBoxes work?*

To put it simply, the basic code behind a flexbox is as simple as this! (we will take an example from the row FlexBoxes in the FlexBox.css file.)

``` css
#container-row {
    display: flex;
    margin-top: 10px;
    margin-bottom: 50px;
    justify-content: center;
    align-items: center;
}
```
